Datos económicos

Cifras económicas por país, en el tiempo

PBI, comercio exterior, inflación, reservas, inversión, deuda y más — compara hasta 3 países a la vez, con datos históricos del Banco Mundial y el FMI.

Esta variable está en la moneda local de cada país, así que no es comparable directamente entre países en el mismo gráfico — úsala para ver la evolución de un solo país a la vez.

Empieza a escribir para buscar y hacer clic en un país de la lista.

Todavía no hay datos cargados Esta herramienta lee los archivos data/*.json que genera el script actualizar_datos.py.
Corre el script una vez, sube la carpeta data/ junto a este archivo, y los datos aparecerán aquí automáticamente.

Fuentes: Banco Mundial (World Bank Open Data) para PBI, exportaciones, importaciones, inflación, reservas, inversión, IED y tipo de cambio; Fondo Monetario Internacional (World Economic Outlook, IMF DataMapper) para deuda del gobierno general como % del PBI — el Banco Mundial tiene huecos serios en ese indicador específico, por eso se usa una fuente distinta solo para esa variable. Los datos se actualizan manualmente cada cierto tiempo, así que pueden no reflejar el año más reciente para todos los países. "Reservas internacionales brutas" no es exactamente el mismo indicador que el RIN publicado por el BCRP para Perú, aunque son comparables en magnitud.
